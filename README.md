# Digital Hub — профиль студента-резидента

Полноценный mobile-first сайт на русском языке: главная, отдельный опрос, персональный профиль и информация об использовании данных. Next.js 16.3.4 (App Router), React 19, TypeScript, Tailwind CSS 4. Приложение предназначено для Vercel, с серверным API и записью в Google Таблицу через подписанный Apps Script webhook.

## Запуск

Нужны Node.js 22.13+ и npm.

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000. Проверки и production-сборка:

```sh
npm test
npm run build
```

После сборки `npm start` запускает production-сервер Next.js на http://localhost:3000. Статический экспорт отключён: отправке результатов нужен сервер. Старую папку `out/`, если она осталась от первой версии, не публиковать.

Для локальной записи скопируйте `.env.example` в `.env.local` и заполните два серверных значения из инструкции ниже. Без подключения сайт явно показывает, что приём результатов недоступен; он не имитирует успешную запись.

## GitHub → Vercel

1. Создайте пустой репозиторий в своём GitHub.
2. Из корня проекта выполните, подставив свой адрес:

```sh
git remote add origin https://github.com/YOUR_ACCOUNT/digital-hub.git
git push -u origin main
```

3. Vercel: **Add New → Project → Import Git Repository**.
4. Framework: **Next.js**. Root Directory: корень этого проекта. Build Command: `npm run build`. **Output Directory оставить стандартным, не `out`**. Node.js: 22.x или совместимая более новая версия. В Environment Variables добавьте `GOOGLE_SHEETS_WEBHOOK_URL` и `GOOGLE_SHEETS_WEBHOOK_SECRET` для Production. Для Preview используйте отдельную тестовую таблицу/скрипт.
5. Нажмите Deploy. Следующие push в main запускают новый деплой.

Если проект находится в подпапке большого репозитория, укажите её как Root Directory. Альтернатива GitHub — официальная CLI: `npx vercel login`, `npx vercel link`, `npx vercel env add GOOGLE_SHEETS_WEBHOOK_URL production`, `npx vercel env add GOOGLE_SHEETS_WEBHOOK_SECRET production`, затем `npx vercel --prod`. Секрет вводите в интерактивном запросе; не помещайте его в git и не используйте префикс `NEXT_PUBLIC_`.

## Google Таблица

Полная настройка: [integrations/google-sheets/SETUP.md](integrations/google-sheets/SETUP.md). Скрипт находится в [Code.gs](integrations/google-sheets/Code.gs).

Схема: браузер → `POST /api/submissions` на Vercel → подписанный запрос в Apps Script → лист «Результаты Digital Hub» в выбранной Google Таблице. Сервер повторно рассчитывает шкалы, не доверяя результатам из браузера. Google-скрипт проверяет подпись и срок запроса, ставит блокировку, проверяет ID на повтор и только затем записывает строку. Таблица не становится публичной.

## Возможности

- 30 вопросов, четыре раздела, один вопрос на экране.
- Главная с описанием проекта, направлениями, порядком участия и FAQ.
- Форма имени, группы и email; явное согласие на отправку.
- 24 поведенческих утверждения (8 шкал по 3 пункта) и 6 практических вопросов.
- Нельзя продолжить без ответа; возврат сохраняет выбор.
- Результат: восемь шкал с пояснениями, две роли, время в неделю, готовность к команде и дедлайнам, три следующих шага.
- Скачивание профиля как UTF-8 TXT, изменение ответов, повторное прохождение.
- Клавиатурная навигация, видимый фокус, фокус на новом вопросе, большие области нажатия, reduced-motion.

## Данные и ограничения

До отправки черновик находится в памяти вкладки, перезагрузка его сбрасывает. После последнего вопроса и при наличии согласия автоматически передаются имя, группа, email, все ответы и итоговый профиль. Успех показывается только после подтверждения Google Таблицы. При ошибке доступен повтор с тем же ID, поэтому сетевой сбой не приводит к дубликату строки. Нет localStorage, сторонней аналитики или внешних шрифтов. Секрет Google-интеграции остаётся на сервере. Содержимое заявок не пишется в логи приложения.

Отправки ограничены по размеру, источнику браузерного запроса, форме данных и наличию согласия. Скрытое поле отсеивает простые боты; в скрипте есть общий лимит 60 записей в минуту. Это базовая защита, не CAPTCHA и не гарантия защиты от целевой автоматизации. При открытом массовом наборе настройте дополнительный rate limit в Vercel Firewall.

Это авторская самооценка для обсуждения участия, не клиническая диагностика и не валидированный инструмент отбора. Опрос не выносит решение о приёме, не присваивает рейтинг кандидата и не заменяет беседу и пробную задачу.

## Логика и структура

`lib/assessment.ts` — вопросы, варианты, шкалы и чистая функция `calculate`.

Формула шкалы: `round(sum / (3 * 4) * 100)`. Ответы 0–4; обратные пункты с `reverse` используют `4 - ответ`. Все пункты равновесные. Пояснения: 0–39 — зона поддержки, 40–69 — развиваемая привычка, 70–100 — выраженная привычка по самоотчёту. Это редакционные границы, не психометрические нормы.

Роли ранжируются по среднему трёх соответствующих шкал. Координатор предлагается только при явной готовности координировать. При равенстве используется порядок объявления ролей/шкал. Время, расписание, стиль общения и интересы не меняют оценки качеств. При отсутствии времени рекомендуется знакомство без регулярных обязательств.

`app/page.tsx` — главная. `app/questionnaire/page.tsx` — страница опроса. `components/assessment.tsx` — форма кандидата, вопросы, профиль и отправка. `app/privacy/page.tsx` — использование данных. `lib/submission.ts` — серверная валидация, расчёт и подпись. `lib/submission-handler.ts` — обработка HTTP. `app/api/submissions/route.ts` — API Vercel. `app/globals.css` — адаптивный дизайн. `tests/` — 16 проверок расчёта, API и Google-приёмника с локальной моделью сервисов Google.

Локальные проверки приёмника не заменяют реальную запись в целевую таблицу: после подключения выполните одно тестовое прохождение с явно тестовыми данными, проверьте строку и повторную отправку того же ID.

## Референс

Изучена страница https://test.hrcs.space/ru/testing/0d2af4d7-ff4a-4c73-9111-7465d7c41f81/result. Доступен только экран завершения: светло-серый фон, белая округлая карточка, зелёная галочка, уведомление об отправке менеджеру. Вопросы и шкалы по этой ссылке недоступны. Использованы общие принципы карточной подачи; тексты, вопросы, логика и оформление созданы отдельно. Уведомление об отправке не перенесено, поскольку такой отправки здесь нет.
